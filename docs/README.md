## Quick Reference

### How many screens?
**49 screens** across 16 feature areas. See `02_screen_inventory.md`.

### What subjects does the app teach?
English · Math · Science · Art & Craft (Drawing, Coloring, Scene Building, Origami)

### What's the color system?
Primary accent: bright yellow-green `#C9E500`. See `03_design_system.md` for all tokens.

### Where does a new feature file go?
Under `lib/features/<feature>/pages/` or `lib/features/<feature>/widgets/`. See `05_folder_structure_guide.md`.
