# Gyan Jyoti (Flutter App)

A fun learning app for kids aged 2–5.

## Getting Started

### Opening in Android Studio / Cursor

1. **Open the project root** (the folder that contains `pubspec.yaml` and the `android` folder), e.g. `flutter_app`, not the `android` folder alone.
2. Run in a terminal at the project root:
   ```bash
   flutter pub get
   flutter doctor
   ```
3. **In Android Studio**: **File → Open** → select the `flutter_app` folder. Wait for Gradle sync. If Flutter isn’t detected, install the *Flutter* plugin and set the Flutter SDK in **File → Settings → Languages & Frameworks → Flutter**.
4. To run: choose a device (Chrome, Android emulator, or Windows) and click **Run** or use `flutter run -d chrome` / `flutter run -d windows`.

### Running the app

- Web: `flutter run -d chrome`
- Windows: `flutter run -d windows` (requires Visual Studio for Windows desktop)
- Android: `flutter run` (with an emulator or device)
